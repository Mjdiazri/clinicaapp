Sistema de gestión de clínica desarrollado en Java OOP. 

<img width="1335" height="684" alt="image" src="https://github.com/user-attachments/assets/5df7dd3f-1414-4691-be99-a9866e6e092d" />

Administra en memoria las entidades de pacientes, médicos y turnos con validaciones y control de agendamiento. Mantiene persistencia de datos mediante archivos CSV generados al finalizar la sesión.

---

## Características Principales

* Gestión integral de Pacientes, Médicos y Turnos.
* Control de duplicados por cédula (pacientes) y por agenda de médico (turnos).
* Manejo estricto de tipos de datos mediante Enumeraciones (EstadoTurno y Especialidad).
* Persistencia automática en formato CSV al cerrar la sesión mediante la clase DatosCSV.
* Estructura modular orientada a objetos respetando la separación de responsabilidades.
